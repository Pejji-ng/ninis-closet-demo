# Everything_nini — Vision Demo

A vision demo for **Everything_nini**, a Lagos-based loungewear brand. Built by Pejji as a "what if your boutique site looked like this" surprise prototype.

## What this is

- Single-page mobile-first site with a soft, intimate boutique feel
- 6 collection cards (Sleep / Lounge / Robes / Gift sets / Bridal / Archive)
- 6 featured product cards with placeholder names + Lagos-boutique pricing (₦24K-₦55K)
- Brand story section
- 3 testimonial cards
- Newsletter signup
- WhatsApp + Instagram + Email CTAs
- "Powered by Pejji" footer

## Visual direction

- **Palette:** soft cream + blush + terracotta + sage accents
- **Typography:** DM Serif Display headers + Inter body (warm boutique pairing)
- **Style:** intimate, woman-led, conversational copy ("Sunday should feel like a hug")

## What this is NOT

- Not an actual ecommerce site (no cart, no Paystack, no real product images)
- Product names + prices + testimonials are placeholders
- Not yet running on a custom domain

## Production roadmap (after Nini sees it + approves)

1. Real product photos + actual product names + actual pricing
2. Cart + checkout via Paystack (or Shopify integration if she prefers)
3. Real testimonials from customers
4. Email capture wired to Mailchimp / Brevo / similar
5. Custom domain (everything-nini.com or similar)
6. Cloudflare Pages with security headers + NDPA cookie consent
7. Optional: Instagram shop integration
